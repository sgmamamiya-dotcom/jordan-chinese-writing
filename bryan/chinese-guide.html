如何使用这份资料

这份表格结合两份老师发的备考材料：好词好句表（按场景分类的句型库）和作文集2026（30篇同学范文，围绕课本几个固定题目改编）。

  1. 先看每个主题下的"结构模板"，理解故事该怎么起承转合。
  2. 再看"可搭配好词好句"，把合适的句子套进对应段落，不要整句照抄范文。
  3. 每次练习挑1个主题，限时20-25分钟仿写一篇，用自己的经历或想象编故事。
  4. 考前一周，脱离这份表，独立完成1-2篇全真模拟，检验是否真正内化。

主题一：分享 / 关爱他人

课本例子：弟弟把心爱的玩具让给哥哥玩，哥哥喜出望外；帮助同学解决困难。

结构模板

  1. 开头：交代人物和场景（如哥哥坐在一边无所事事）
  2. 发展：一方察觉到对方的情绪/困难，主动付出（对话+动作）
  3. 高潮：对方的反应（惊喜/感动）
  4. 结尾：点出"助人为快乐之本"或类似道理

可搭配好词好句

  • 内心感受"原来，帮助别人是一件这么快乐的事！我深深地体会到'助人为快乐之本'的感受。"
  • 内心感受"老师竖起了大拇指称赞我时，我的心里就像喝了蜜糖一样，觉得甜滋滋的。"

主题二：沉迷电子产品被家长发现

课本例子：孩子夜深人静还在玩电脑游戏，被妈妈发现。

结构模板

  1. 开头：交代时间场景（夜深人静/十一点半），制造悬念（房间还亮着灯）
  2. 发展：家长疑惑地走近查看，发现真相
  3. 高潮：家长的表情/动作+对话（生气/失望）
  4. 结尾：孩子悔悟，用俗语总结教训

可搭配好词好句

  • 做错事"我知道自己错了，心里就像有一把千斤重的铁锤敲击着，十分难受。"
  • 结尾"从此以后，我再也不敢把妈妈的话当成耳边风了。正所谓'不听老人言，吃亏在眼前'，这句话说得一点也没错！"
  • 声音"'铃……'闹钟响了"——可用于制造时间转折

主题三：下课铃声 / 课室场景

课本例子：下课铃声响起，同学们一窝蜂冲出课室（去食堂/抢位置/插队等）。

结构模板

  1. 开头：铃声起，课室从安静变热闹（对比手法）
  2. 发展：同学们的动作描写（争先恐后）
  3. 转折：意外事件发生（如插队、摔倒、争执）
  4. 结尾：事件解决，点出道理

可搭配好词好句

  • 声音"'铃……'放学的铃声响了。"
  • 动作"枪声一响，赛跑选手们飞一般地向终点奔去。"（可改写成冲向食堂）
  • 动作"同学们便一窝蜂地跑出课室。"
  • 动作"我三步并作两步地向办公室跑去。"

主题四：记忆 / 回忆类作文

课本例子："记忆就像一张渔网，捕捉了生活中大大小小的事物"——以此为开头，回忆一件难忘的事。

结构模板

  1. 开头：用比喻句引出"记忆"主题
  2. 发展：具体叙述一件难忘的事（时间、地点、人物、经过）
  3. 高潮：事件中的转折或情绪起伏
  4. 结尾：说明这件事为什么难忘、学到了什么

可搭配好词好句

  • 开头"记忆就像一张渔网，捕捉了生活中大大小小的事物。许多事情随着时间的流逝渐渐被淡忘，但有一件事却让我记忆犹新……"
  • 开头结尾通用"有人说，人生像一个口袋。在我人生的口袋里，有许多难忘的事情。"
  • 结尾"'经一事，长一智'，这件难忘的事，我会把它装进我人生的口袋里，当作是我上过宝贵的一课。"

主题五：运动会

课本例子：一年一度的运动会，同学们兴奋参与比赛，最终获胜或努力拼搏。

结构模板

  1. 开头：天气+场景（艳阳高照、校园热闹）
  2. 发展：比赛前的准备、紧张心情
  3. 高潮：比赛过程（动作+周围呐喊声）
  4. 结尾：结果+感受（无论输赢都有收获）

可搭配好词好句

  • 比赛场面"球赛开始了，四面响起了'加油，加油'的喝彩声。"
  • 比赛场面"发令枪一响，他像离弦的箭一样向前跑，把所有的对手远远地抛在后头。"
  • 天气开头"一个烈日当空的下午，太阳像火球般高挂空中，天气热得令人发狂。"

主题六：安全教育 / 危险经历

课本例子：家长外出前叮嘱孩子在家要小心，孩子却做了危险的事，事后吸取教训。

结构模板

  1. 开头：家长外出前的叮嘱（对话）
  2. 发展：孩子独自在家时发生的危险状况
  3. 高潮：惊险的瞬间+内心恐惧
  4. 结尾：平安脱险，吸取教训，以后会注意安全

可搭配好词好句

  • 内心感受"妈妈见孩子平安无事，心中的一块大石头终于落了地。"
  • 结尾"'前事不忘，后事之师'，经过这件事，我吸取了教训，以后会注意安全，不会再犯同样的错误。"

主题七：插队 / 违反规矩后悔改⭐ 重点

这是范文集中出现次数最多的主题（多篇不同版本），值得重点掌握。课本例子：下课后同学到食堂排队，有人插队被发现，被老师批评后道歉改正。

结构模板

  1. 开头：铃声响，同学们冲向食堂排队
  2. 发展：主角因心急/贪玩而插队，被同学/学长发现
  3. 高潮：被带到办公室，老师严厉批评（外貌+语言描写）
  4. 结尾：主角道歉、重新排队，老师称赞，主角明白遵守规矩的重要性

可搭配好词好句

  • 动作"他知道自己闯祸了，一溜烟地跑出课室，逃得无影无踪。"
  • 内心感受"他心里像十五个吊桶打水——七上八下。"
  • 形容表情"老师板起了面孔，眉毛竖成了倒'八'字，眼睛瞪得又圆又大，像一座活火山随时都会爆发。"
  • 结尾"'经一事，长一智'，经过这件事，他明白了在学校要遵守秩序，不能插队。"
  • 结尾"'早知今日，何必当初。'经过这件事，他学到了插队是个没有礼貌和没有教养的行为。"

考前复习小贴士

  • 优先掌握主题七（插队/违规改过）：范文集中出现次数最多，说明老师很重视，也最可能以变体形式出题（如插队、闯祸、破坏规矩等）。
  • 每篇范文的通用结构其实很相似：场景开头 → 事件发生 → 人物表情/动作/心理描写 → 结尾用俗语点题。掌握这一套路，遇到任何新题目都能套用。
  • 好词好句表里的"开头/结尾"通用句（如"人生像一个口袋"、"经一事，长一智"）几乎适用于所有主题，建议优先背熟。
  • 练习安排建议：
    1. 9月最后一周：分类抄写好词好句，每天1个场景
    2. 10月第一周：每天仿写一篇不同主题（重点练主题七）
    3. 10月6-8日：2次全真模拟，不看小抄，计时完成
